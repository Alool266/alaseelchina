# الأصيل / Al Aseel — static site

Premium one-page marketing site for **الأصيل للاستيراد والتصدير** (Al Aseel Import & Export).

- Domain: `alaseelchina.com` (`CNAME` included)
- Stack: static HTML / CSS / JS (GitHub Pages ready)
- Contact: WhatsApp only — no backend, forms, or login
- Brand colors: navy `#0B2A5B`, red `#D7262E`, background `#F5F7FB`

## Preview locally

Open `index.html` in a browser, or from this folder:

```bash
npx --yes serve .
```

Then visit the URL shown (usually `http://localhost:3000`).

## Deploy (GitHub Pages)

1. Push this folder to a GitHub repository.
2. Settings → Pages → Deploy from branch (`main` / root).
3. Custom domain: `alaseelchina.com` (already in `CNAME`).
4. Point DNS (Porkbun or other) A/AAAA or CNAME records to GitHub Pages.
